## 主要内容

《日月潭》介绍了我国台湾省最大的湖泊——日月潭的地理位置、自然景观、湖面划分、不同时段的景色变化以及其作为旅游胜地的吸引力。

课文共计 11 自然段，依次介绍：
1. 日月潭是台湾省最大的湖
2. 位于台湾省中部山区
3. 群山环绕、树木茂盛，周围有许多名胜古迹
4. 湖很深，湖水碧绿
5. 湖中央有小岛，把湖水分成“日谭”和“月潭”
6. 日谭——北边像圆圆的太阳
7. 月潭——南边像弯弯的月亮
8. 清晨湖面薄雾朦胧
9. 黎明时分晨星与山上灯光倒映湖中
10. 正午太阳高照，美景清晰可见
11. 细雨蒙蒙时，景物朦胧如童话仙境
12. 日月潭风光秀丽，吸引了许多中外游客
